## Nestify

Nestify is a full-stack web application that helps users discover interior design styles, create moodboards, compare design ideas, manage projects and connect with interior designers.

## Features

- User authentication
- Browse interior design styles
- Save favorites
- Create and share moodboards
- Interior designer profiles
- AI assistant
- Budget estimator
- Room detector
- Admin dashboard

## Technologies

Frontend
- React
- Vite
- Tailwind CSS

Backend
- Node.js
- Express
- Prisma ORM

Database
- PostgreSQL

Other
- Cloudinary
- JWT Authentication
